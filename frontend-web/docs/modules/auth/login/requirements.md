# 登录界面元素需求

## 1. 目的

`/login` 是项目的统一登录入口，负责让已注册用户进入当前分析工作台。

登录结果必须由 Java 后端作为最终判断依据，前端只负责收集输入、展示状态和跳转。

## 2. 依据

- `infra/mysql/schema/20260827_auth_tables.sql`
- 根 `AGENTS.md` 与 `frontend-web/README.md`
- `frontend-web/src/pages/LoginPage.vue`

## 3. 必须包含的元素

1. 页面标题
2. 页面副标题或品牌说明
3. 账号输入框
4. 密码输入框
5. 登录按钮
6. 错误提示区
7. 注册跳转入口
8. 注册成功提示区

## 4. 元素要求

### 4.1 账号输入框

- 标签建议为 `账号`
- placeholder 必须明确支持多种登录标识，例如 `用户名 / 手机号 / email`
- 支持输入 `username`、`email`、`phone`
- 自动补全建议使用 `autocomplete="username"`
- 输入内容提交前应做去首尾空格处理

### 4.2 密码输入框

- 标签建议为 `密码`
- placeholder 建议为 `请输入密码`
- 自动补全建议使用 `autocomplete="current-password"`
- 默认类型必须为密码框

### 4.3 登录按钮

- 文案建议为 `登录`
- 提交中应显示加载态
- 提交期间禁止重复点击

### 4.4 错误提示区

- 仅展示统一错误文案
- 不得暴露账号是否存在、密码是否正确、是否被锁定等精确信息
- 后端详细失败原因只进入审计日志，不直接暴露给前端

### 4.5 注册跳转入口

- 提供跳转到 `/register` 的入口
- 若登录页携带注册成功标记，应展示成功提示并可预填账号标识

## 5. 交互与校验

1. 用户输入账号和密码后可按回车提交
2. 任一字段为空时应阻止提交
3. 登录失败时停留在当前页并显示错误提示
4. 登录成功后跳转到 `next` 指定页面，默认跳转到 `/`

## 6. 关联后端数据

- `auth_user`：用于匹配账号、校验状态和写入最近登录信息
- `auth_login_log`：用于记录登录尝试、结果、失败原因和客户端信息

## 7. 非目标

- 记住我
- 忘记密码
- 短信验证码
- 图形验证码
- SSO
- 多因素认证
