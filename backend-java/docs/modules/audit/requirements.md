# Java Audit 模块需求

## 1. 模块定位

`audit` 模块负责任务审计、关键操作留痕、最终 SQL 归档、失败原因记录和后续问题追溯。

## 2. 当前代码现状

当前仅存在返回固定示例的 `GET /api/audit/demo`；任务审计、事件持久化和查询能力尚未实现。

## 3. 核心职责

1. 记录任务创建操作
2. 记录任务状态变化
3. 保存最终 SQL
4. 保存结果状态和失败原因
5. 保存任务 trace 关联关系

## 4. MVP 功能需求

1. 支持按任务维度查询审计详情
2. 支持按用户维度查询操作记录
3. 支持查看任务事件时间线
4. 支持查看高风险拦截原因
5. 支持保存用户确认过的 SQL 和图表摘要

## 5. 必存字段

1. `taskId`
2. `traceId`
3. `tenantId`
4. `userId`
5. `datasetIds`
6. `question`
7. `sqlText`
8. `status`
9. `errorMessage`
10. `startedAt`
11. `finishedAt`

## 6. 边界约束

1. 不负责实时任务执行
2. 不负责权限主判断
3. 不负责图表渲染

## 7. 验收标准

1. 每个分析任务都有可查询的审计记录
2. 失败任务可以定位失败原因
3. 高风险拦截任务可以看到规则命中信息
