# Java Auth 模块需求

## 1. 模块定位

`auth` 模块负责当前系统的登录、登出、令牌、用户身份、角色权限、租户信息和任务最小权限上下文生成。它是 Java 到 Python Agent 的权限边界入口。

## 2. 当前代码现状

当前仅存在 `GET /api/auth/context-demo` 骨架接口，用于返回 `TaskAccessContext` 示例。MVP 需要在此基础上补齐真实认证鉴权能力。

## 3. 核心职责

1. 用户登录
2. 用户登出
3. 令牌刷新
4. 获取当前登录用户信息
5. 获取当前用户对任务可用的最小权限上下文
6. 维护用户、角色、租户和数据集授权关系

## 4. MVP 功能需求

1. 支持账号密码登录
2. 支持 JWT 或等价登录令牌
3. 支持退出登录
4. 支持获取当前登录人基本信息
5. 支持构造 `TaskAccessContext`
6. 支持将授权数据集集合作为任务上下文传给 `job` 模块
7. 支持敏感字段脱敏配置，例如 `phone`、`id_card`

## 5. 最小权限上下文要求

`TaskAccessContext` 至少包含：

1. `tenantId`
2. `userId`
3. `roles`
4. `allowedDatasets`
5. `maskedColumns`
6. `readonly`

## 6. 边界约束

1. 不负责 Agent 编排
2. 不负责 SQL 生成
3. 不允许 Python 端绕过此模块直接做业务授权判断

## 7. 验收标准

1. 用户可以登录并获得令牌
2. 用户可以获取自己的身份信息
3. 创建任务时能生成准确的数据集授权上下文
4. 未授权用户不能访问他人数据集
