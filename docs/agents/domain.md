# 领域术语与决策记录

## 查阅规则

- 任务涉及项目领域概念时，按需读取根目录 `CONTEXT.md`。它只统一术语，不描述代码实现状态或架构方案。
- 任务涉及架构或长期取舍时，只读取相关的 `docs/adr/` 决策。
- 发现术语或决策记录与当前代码、用户需求不一致时，核实并说明差异；不要把文档中的目标或历史决定当成已实现行为。

## 文档维护

- 本仓库采用 single-context 布局：项目领域术语集中维护在根目录 `CONTEXT.md`，长期架构取舍记录在 `docs/adr/`。
- 只有出现需要统一的项目领域概念时才增补 `CONTEXT.md`；只记录已从用户需求或代码中确认的含义，不写实现细节、进度、临时笔记或推测。
- 不为每项功能新增 ADR；仅记录需要长期保留的架构决策。
